Why mathra

    
One small library, the same output everywhere: the terminal, Rust, Python and the browser.

    

      

        

        
It speaks the equation

        
The SVG's <title> carries the phrase a screen reader says: “1 over 2”, not “image”.

      

      

        
pt-BR

        
It knows the locale

        
In pt-BR, 3,14 is one number, \sin is written sen and the speech is in Portuguese.

      

      

        

        
It forgives broken input

        
Typos and editor leftovers are fixed and reported as numbered warnings. Strict refuses them, like TeX.

      

      

        
18.7 µs

        
It is fast and stable

        
Mean time per equation on the corpus. The same input always writes the same bytes.

Use it

    
The core is a Rust crate; the CLI, Python and WebAssembly packages wrap the same code.

    

      

        
Terminal


cargo install mathra-cli
mathra 'x \le 2.75' -o inequality.svg
mathra '3,14 + \sin x' --locale pt-BR
mathra 'x = -1' --speech
mathra '\vertA\vert' --explain

      

      

        
Rust


// cargo add mathra
let r = mathra::convert("3.14", &mathra::Options::default())?;
println!("{}", r.svg);
println!("{}", r.speech);

      

      

        
Python


import mathra

svg = mathra.tex_to_svg(r"\sin x = 0.5")
tree = mathra.tex_to_tree("3,14", locale="pt-BR")

      

      

        
Browser (WebAssembly)


await wasm_bindgen();
const { texToSvg, render } = wasm_bindgen;
const svg = texToSvg("3,14", "pt-BR");
const all = JSON.parse(render("x^2"));
// svg, speech, text, tree, applied, warnings

      

    


    

      
What the SVG carries

      
    
        
  • Speech in <title>, linked with aria-labelledby.
    • 
        
  • The source LaTeX and the tree of meaning in <metadata>.
    • 
        
  • Color from the page (currentColor), size in em, baseline aligned with the text around it.
    • 
        
  • A transparent text layer for selection, reused glyphs and ids unique to each equation.
    • 
      


      
Broken LaTeX

      
By default mathra draws what it can and reports what it fixed, as E-REC-1 to E-REC-9 (spec/tolerance.md). Every rule that shapes the output is numbered in spec/rules.md; the Rules tab shows which ones acted on your equation.


      
What it converts

      
Fractions, roots, scripts and limits, stretchy delimiters, matrices and array, cases, aligned, accents and braces, \text, alphabets, \cancel, \boxed, \color, siunitx, basic \ce, physics and braket, \newcommand and friends, amscd diagrams, and the computed \divchave and \contaarmada. The full list is in the README.
